# 00 Hypertext

00 Hypertext Non-Commercial and 00 Hypertext Mono Non-Commercial by Dinamo
(https://www.dblzr.com/fonts). These non-commercial font files are supplied for
this portfolio demo. Replace them with appropriately licensed commercial files
or a free alternative before commercial use. Only Regular, Italic, Medium and
Medium Italic sans, and Regular and Medium mono, are loaded by the application.

Wagram Non-Commercial Regular supplies the wordmark and display headings. All supplied font files, including Wagram, are tracked in Git so deployment builds have the same assets as local development.
